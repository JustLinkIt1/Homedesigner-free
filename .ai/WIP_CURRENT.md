## Guardrails / house rules

- Keystore files (`android/keystore*.{properties,jks}`) are gitignored,
  sandbox-local — never stage/commit/log them.
- Never put the model identifier in commits/PRs/code.
- Release train (only if bumping app version): `npm pkg set version=1.0.NN` →
  `node scripts/sync-version.mjs` → sed both version fields in
  `package-lock.json` (lines 3 & 9) → `npm run build` → `npx cap sync android`
  → `cd android && ANDROID_HOME=/opt/android-sdk /opt/gradle/bin/gradle
  bundleRelease -q`. Verify AAB signer SHA256 ==
  `EE:D4:E3:A9:11:BC:92:9A:D3:CD:33:36:FF:BF:32:C0:22:4A:1F:C5:21:BE:B1:13:02:F5:A0:7E:5F:00:6A:00`;
  versionCode = 100NN. Update `CHANGELOG.md` (newest first) when shipping.
- Lint is `--max-warnings 0`; remove scratch `_*.mjs` before linting.
