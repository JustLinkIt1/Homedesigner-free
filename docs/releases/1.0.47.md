# HomeDesigner Free 1.0.47

Android version code: `10047`

Source release commit: `5a0cfd4139bcc433508a8186308f374eef76a35e`

## Google Play release notes

Explore furniture faster with interactive 3D previews, clearer room and type
categories, and 32 new cloud-hosted interior models. Sample homes now use more
real furniture. This release also improves Galaxy S25 fluidity, direct 3D
placement, mobile controls, and wall painting so finishes stay within the room
you selected.

## Technical summary

- Adds validated, cached, on-demand R2 catalog ingestion with safe offline and
  corrupt-model fallbacks.
- Adds interactive 3D previews and lazy GLB loading.
- Adds room/type grouping while preserving search, recents, and Pro gating.
- Moves static 3D scenes to demand rendering and lowers mobile render cost.
- Uses lightweight furniture interaction proxies for drag hit testing.
- Adds independent room-side wall finish intervals without splitting structural
  walls or covering door/window openings.
